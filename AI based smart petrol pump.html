Safety Monitoring Process


Existing CCTV cameras provide video input. The proposed monitoring system analyzes safety-related conditions and generates an alert when a risk is detected. The employee or owner can then take appropriate action and the incident can be recorded.

ℹ️ About Project

AI Based Smart Petrol Pump Management & Safety System

Project Objective


The proposed system aims to improve safety monitoring at petrol pumps by using CCTV-based monitoring, risk detection, alerts and incident records.


Safety Risks


  • 🔥 Fire / Flame
  • ☁️ Smoke
  • 💧 Fuel Leakage / Spillage
  • 🚬 Smoking
  • 📱 Unsafe Phone Usage

System Components


  • Existing CCTV cameras
  • Monitoring dashboard
  • Safety detection module
  • Alert system
  • Incident records
